One line of an out-of-office auto-reply, for The Funniest Out-of-Office
on make.fun. Out until Monday — and the inbox has been handed to the
office printer, which has jammed, so officially no one is working today.
The frame is a reply a real person would set, the handover is one
concrete office object, and the twist is that the printer's jam shuts
down the whole office, not just the email. No borrowed houseplant joke,
no template voice — every word earns its place, exactly what the brief
asks for.

## Run it

```sh
python3 main.py
```

This writes the reply to `/output/entry.txt` (UTF-8, 1–140 characters).
